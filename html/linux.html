GainDrive: Linux

Connects to your GainDrive server (or any other Subsonic-compatible one) and plays your audio and video collection on your Linux desktop.

download Download GainDrive Server
What's inside

App features.

computer

Native GTK app

  • checkNative GTK4 app written in C++ using Gtkmm (no electron or other cruft).
  • checkPlays audio and video using GStreamer.
  • checkMinimal footprint, only 14MB for the full package.
queue_music

Browse and play

  • checkBrowse by artist, album or playlist with cover art pulled in automatically.
  • checkGapless playback, queueing and search across your whole library.
  • checkBuilt-in 10-band equalizer with custom presets.
keyboard

Keyboard navigation

  • check[soon] Play/pause, seek, next/previous and search, all without reaching for the mouse.
cast

Cast

  • checkOne-click cast to any Chromecast on the network, using its own custom Chromecast implementation.
  • check[soon] Option to cast only audio for video files, keeping the video playing in the browser (e.g. to cast audio to an amp).
Get the app

Download for Linux.

Packages are built for Ubuntu 24.04, on x86_64 (amd64) and ARM (arm64).

Ubuntu 24.04

Grab the .deb for your architecture from the latest release, then install it with apt.

download Download for Ubuntu
sudo apt install ./gaindrive-player-*.deb
